 
# CodeAlpha Data Analytics Internship

## Project Overview
This project demonstrates data analysis, data visualization, and web scraping using Python.

## Task 1: Exploratory Data Analysis (EDA)
- Created a sample sales dataset.
- Checked missing values and duplicate records.
- Calculated sales statistics.
- Analyzed product-wise and city-wise sales.

## Task 2: Data Visualization
Created the following charts:
- Product-wise Total Sales — Bar Chart
- City-wise Total Sales — Bar Chart
- Product-wise Sales Distribution — Pie Chart
- Quantity Sold by Product — Bar Chart
- City-wise Sales Distribution — Pie Chart

## Task 3: Web Scraping
- Scraped book titles, prices, and availability.
- Extracted 20 books from the first page of Books to Scrape.
- Saved the collected data as a CSV file.

## Tools Used
- Python
- Pandas
- Matplotlib
- BeautifulSoup
- Requests
- Google Colab

## Dataset Note
The sales dataset was created for practice. Web scraping was performed on the Books to Scrape demonstration website.

## Conclusion
This project provided practical experience in exploratory data analysis, data visualization, and web scraping using Python.
